## How this repo is organised

Two layouts, for historical reasons:

- **`<number>-<problem-slug>/`** — created automatically by the LeetSync
  browser extension on each accepted submission. Each holds the problem
  statement as `README.md` plus the solution file. Commit messages carry
  the runtime and memory percentiles.
- **`Arrays & Hashing/`, `Two Pointers/`** — earlier solutions, added by hand and
  grouped by NeetCode topic (24 files, all C++).

The numbered folders are tool-managed — new solutions land there automatically,
so they are deliberately left flat rather than reorganised by topic.

Regenerate this file after syncing new solutions:

```bash
python3 scripts/update_readme.py
```
